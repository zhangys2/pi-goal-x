# Process presets

## Question
Should presets be (A) named profiles that set existing settings and can be customized afterward, (B) guided setup questions that configure settings without persistent preset names, or (C) another model? Which configurations should “lightweight,” “structured,” and “audited” actually change, and should presets apply globally or per project?

## Resolution
Use named profiles for lightweight, structured, and audited modes; configure existing settings, allow subsequent customization, and apply per project. User agreed to this direction. Exact setting values remain open and must be settled before implementation.
