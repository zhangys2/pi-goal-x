# First-goal onboarding

## Question
What should the first-goal onboarding experience add beyond the existing README and `/goal` guided drafting flow: (A) a short inline walkthrough/sample goal, (B) only improve the current `/goal` prompts, or (C) another specific format? Define the success signal and avoid duplicating existing documentation.

## Resolution
Use a short inline walkthrough with a sample goal. Success should be evaluated by whether a new user can discover and complete the existing draft → confirm flow; do not duplicate the README. User agreed to this direction.
