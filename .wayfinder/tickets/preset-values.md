# Preset configuration values

## Question
Which existing settings should each project preset change? In particular, should lightweight disable tasks/contracts or simply use conservative defaults; should structured enable task/contract tracking; and should audited enable the auditor, precheck, or both? Defaults must be visible, change only settings controlled by the preset, and remain user-customizable.

## Resolution
Lightweight disables tasks and contracts; structured enables tasks and contracts; audited enables tasks, contracts, and the auditor. Precheck remains off in all presets. Profiles are per-project, named, based on existing settings, and customizable. User agreed.
